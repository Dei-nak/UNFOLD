# UNFOLD

Локальний вебзастосунок для планування дня, перегляду календаря й порівняння сценаріїв.

## Запуск у Windows

Відкрийте термінал у цій папці, виконайте `npm start` і перейдіть на
[http://127.0.0.1:4173](http://127.0.0.1:4173). Потрібен Node.js 20 або новіший.
Встановлювати залежності не потрібно. Для перевірки коду виконайте `npm test`.

## Структура

- `index.html` — оболонка застосунку.
- `src/views.js` і `src/ui.js` — екрани та спільні елементи інтерфейсу.
- `src/main.js` — навігація, форми й обробка дій.
- `src/store.js` і `src/dates.js` — дані, локальне збереження й календарні обчислення.
- `src/base.css` і `src/workspace.css` — спільні стилі та оформлення робочого простору.
- `server.js` — локальний запуск.

Початковий розклад і AI-пропозиції демонстраційні. Створені події, думки
й сценарії зберігаються в браузері для локальної адреси застосунку.
Дані зі старого HTML-файлу браузер автоматично не переносить.
